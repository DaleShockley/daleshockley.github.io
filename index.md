# Hi, I'm Dale Shockley

I'm a technical program manager based in Sunnyvale, California. My job, most days, is getting handed something that's already a mess: a stalled database migration, a security program nobody owns, an AI rollout that leadership wants finished yesterday. I turn it into a plan a real team can actually execute, then I stay on it until it ships.

I've done this as a contractor at places like Intuit and Pinterest, and before that spent almost five years at Accenture, coaching other program managers through the same kind of work. Most of the actual skill is staying calm when a program's on fire and everyone in the room is looking at you for the plan.

This site is a change of pace. I usually manage the people who build things rather than build them myself, so I wanted to get my hands back on the keyboard. It's a Jekyll site hosted on GitHub Pages, built as a learning project as much as a portfolio. The README in this repo walks through how it's put together, and the [projects page](/projects/) has what I've actually shipped.
